# 13. 화면 지도 (어떤 페이지를 만드는가)

| 항목 | 내용 |
|------|------|
| 주 역할 | 지침서(11)대로 만들 때 생기는 화면 목록과 각 화면에 들어가는 것 |
| 부 역할 | 개발 순서(11 10장)와 화면의 대응 |
| 주 담당 / 부 담당 | 리드 프로덕트 디자이너 / 스마트제조 수석연구원 |
| 마지막 수정 | 2026-11-02 |

> 지침서 3.1절의 뼈대는 **편집기 1개 + 범위 2개(설비·공장) + 모드 3개(편집·실행·비교) + 라이브러리 관리 1개**입니다. 그래서 페이지가 많지 않습니다. 화면 하나가 범위와 모드에 따라 모습을 바꾸는 구조이고, 별도 페이지는 아래 여섯 묶음뿐입니다.

## 1. 한눈에 보기
```
랜딩 (bse-digital-twin.vercel.app)  ── Build ──▶  BSE Studio
                                      ── Monitor ─▶  (V2, Evolve)

BSE Studio
├─ A. 로그인 / 회사(테넌트) 선택
├─ B. 홈 (프로젝트·설비 라이브러리·공장 목록)
├─ C. 편집기 ── 범위 = 설비 (머신빌더)   ┐ 모드: 편집 · 실행 · 비교
│            └─ 범위 = 공장 (팩토리빌더) ┘ (같은 화면, 팔레트와 패널만 바뀜)
├─ D. 시나리오·리포트 (비교 모드의 확장 화면)
├─ E. 라이브러리 관리 (블록·설비·템플릿·치수 표, 공급자용)
└─ F. 설정 (계정·권한, 좌표·단위, 내보내기)
V2: G. Monitor(Evolve) 대시보드 · 공유 뷰어 · 변환(AAS/USD)
```

## 2. 화면별 내용 (V1)

### A. 로그인 / 회사 선택
- 로그인, 회사(테넌트)별 데이터 분리, 역할(편집/열람) — 지침서 11장
- 처음엔 단순하게. 권한 고도화는 V2

### B. 홈
| 영역 | 내용 |
|------|------|
| 설비 라이브러리 | 내가 만든 설비 카드 목록(L1/L2 등급 표시), 템플릿 3종, 새 설비 만들기 |
| 공장 목록 | 공장 파일(factory.json) 목록, 새 공장 만들기 |
| 최근 작업 / 시나리오 | 최근 연 파일, 최근 실행 결과 |

### C. 편집기 (핵심 화면, 코드 1벌)
공통 틀: 가운데 **3D 뷰포트**, 왼쪽 **팔레트**, 오른쪽 **속성 패널**, 아래 **상태·태그 표**, 위 **도구 막대**(이동·회전·스냅·측정·실행 취소·저장·모드 전환). 지침서 4원칙대로 모든 조작은 편집 명령(add_block, set_param …)을 부르는 버튼일 뿐.

| 범위 | 팔레트 | 속성 패널 | 아래 패널 | 특유 도구 |
|------|--------|-----------|-----------|-----------|
| **설비 (머신빌더)** 11 6장 | 블록 10분류(구조·반송·공압·전동·로봇·센서·워크·피더·공정·이동체) | 블록 파라미터, 치수 표(verified 표시), 관절(스트로크·속도), fidelity 등급 | 태그 표(I/O 엑셀 붙여넣기·내보내기), 수동 조작 패널(태그 ON/OFF), 간이 시퀀스 | 외곽 가이드 박스, 레퍼런스 사진 2점 스케일, glb·URDF 불러오기, 설비 카드 만들기, DXF 출력 |
| **공장 (팩토리빌더)** 11 7장 | 설비 카드 + 공장 블록 약 25종(바닥·벽·기둥·지붕·층·문·마킹·랙·펜스·드롭·도킹) | 인스턴스 값(tagPrefix, 카드 덮어쓰기), 자재 흐름 연결·분기 비율, 층 관리 | 설비 목록, 흐름·동선 표 | 평면도 깔기(DXF·이미지), 선 그리기→벽, 폴리곤→바닥·구역, 기둥 격자, 동선 자동 생성, DXF·PDF 출력 |

모드 (두 범위 공통, 11 8장):
| 모드 | 화면에 더해지는 것 |
|------|--------------------|
| 편집 | 위 표 그대로 |
| 실행 (데모 시뮬) | 재생·일시정지·배속(1~10), 신호 표 실시간 값, 지표 패널(처리량·병목·가동률·WIP·리드타임), 리플레이 타임라인 |
| 비교 | 시나리오 목록(스냅샷 + 파라미터), 정식 실행(서버, N회) 보내기, 비교표 → D 화면으로 |

### D. 시나리오·리포트
- 시나리오 만들기·복제·파라미터 덮어쓰기, 실행 설정(기간·반복·시드)
- 결과: 지표 표 + 이벤트 로그 + 리플레이, 대안끼리 비교표, PDF 리포트
- 최적화: 레이아웃·버퍼·밸런싱 루프 실행, 세대별 개선을 애니메이션으로 재생

### E. 라이브러리 관리 (공급자용)
- 블록 정의·치수 표·설비 템플릿의 버전과 공개 범위, verified 표시 관리
- 메이커 CAD는 넣지 않음(11 11장). 일반 사용자에겐 안 보임

### F. 설정
- 계정·역할, 회사 정보
- 좌표·단위 확인(mm/deg, Z-up — 바꾸지 못하게 표시만), 내보내기 기본값(DXF·엑셀 양식)

## 4. 개발 순서와 화면 대응 (11 10.1절)
| 순서 | 단계 | 이때 생기는 화면 |
|------|------|------------------|
| 1 | 규약·스키마·API | 화면 없음 (데이터·명령 목록·저장소 뼈대). 편집기 빈 틀만 |
| 2 | 머신빌더 | **C-설비** 전체 + B 홈의 설비 라이브러리. 게이트 1: 기준 설비 3종 재현 |
| 3 | 팩토리빌더 | **C-공장** + B 홈의 공장 목록 |
| 4 | 시뮬 엔진 | C의 실행 모드, 비교 모드 기본 |
| 5 | 리포트·최적화 | **D** 전체 |
| 6 | 마감 | A·E·F 다듬기, 성능, 문서 |

## 5. 화면 공통 규칙
- 색·글꼴·로딩 문구는 [04 디자인 가이드](04_DESIGN_GUIDE.md) (남색 단일 테마, 로딩 문구 어휘 6개)
- 한국어 기본, 영어 UI는 V2. 1920×1080 기준, WebGL2 필수
- 기존 `BSE_STUDIO/apps/web`(VEXPLOR 파생 AAS 도구)의 화면과 코드는 쓰지 않음. 빌더는 `BSE-Digital-Twin` 저장소의 `apps/`에 처음부터, AAS 변환은 IDTA 공식 라이브러리 + 우리 매핑, 현장 연결은 게이트웨이 방식 (D-31)
- 구현 위치: `apps/web/src` — `screens/`(홈 B `Home`, 설비 편집기 C `MachineBuilder`, 공장 자리 `FactoryBuilder`(3단계), 실행 보기 `Simulate`, V2 자리 `Evolve`), `panels/`(팔레트·속성·아래 패널·`Thumb` 위에서 본 그림), `three/Viewport.tsx`(3D, 보기 solid/lines). 주소 해시 `#home #machine #factory #simulate #evolve`. 화면은 명령만 호출한다(`store.ts`의 `dispatch`, `open`). 2026-11-02 C 화면 편집·실행 모드, Simulate 보기 구현(D-37), 비교 모드는 4단계
- 머리 메뉴 = 집 아이콘(홈) · Build(설비·공장) · Simulate · Evolve. 템플릿 3종은 `packages/engine` 의 `MACHINE_TEMPLATES`(기준 설비 3종, 게이트 1 테스트와 같은 함수)
