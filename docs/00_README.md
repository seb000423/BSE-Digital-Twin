- **코드 규칙**: 저장소 루트의 [CLAUDE.md](../CLAUDE.md)(원본은 [standard/CLAUDE.md](standard/CLAUDE.md))를 Claude는 코드 작업 전에 반드시 읽습니다.

## 문서별 역할 (주 / 부)

**주 역할**은 그 문서가 *결정하고 책임지는 것*, **부 역할**은 *다른 문서를 돕는 보조 기능*입니다.
한 가지 내용은 한 문서에서만 "주"로 다루고, 다른 문서는 링크만 겁니다.

|---|------|----------------|----------------|---------|---------|
| 01 | [개요](01_OVERVIEW.md) | 왜 만드는지, 누구를 위한 것인지 | 새로 합류한 사람의 첫 안내서 | MR | PD |

| 03 | [아키텍처](03_ARCHITECTURE.md) | 시스템 구성과 연결 방식 | 기술 선택 이유 기록 | MR | OT, RS |
