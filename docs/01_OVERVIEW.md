# 01. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 주 역할 | 왜 만드는지, 누구를 위한 것인지 정의 |
| 부 역할 | 새로 합류한 사람의 첫 안내서 |
| 주 담당 / 부 담당 | 스마트제조 수석연구원 / 리드 프로덕트 디자이너 |
| 마지막 수정 | 2026-11-02 |

> 제품의 세부 기준은 [11 개발 지침서 R1](11_BSE_DT_DEV_STANDARD.md) 입니다 (D-19). 이 문서는 그것을 쉬운 말로 요약한 것이고, 다르면 기준서가 우선입니다.

## 1. 한 줄 소개
BSE : Digital Twin은 웹 브라우저에서 설비와 공장을 3D로 만들고(Build), PLC 신호 기준으로 동작과 물류를 미리 돌려 보고(Simulate), 그 결과를 현장 데이터와 최적화로 되돌려 계속 발전시키는(Evolve) 스마트팩토리 디지털 트윈 플랫폼입니다. 설치 없이 브라우저에서 동작합니다.

## 2. 해결하려는 문제
- **바꾸기 전에 볼 수 없다**: 라인 배치, 설비·로봇·AMR 도입 효과를 숫자로 비교할 방법이 없음
- **도면 없는 설비가 많다**: 현장 설비를 3D로 다시 만드는 데 비용이 큼 → 블록을 조립해 짧은 시간에 재현
- **디지털 트윈은 비싸고 어렵다**: 기존 도구는 전문 인력과 긴 구축 기간이 필요 → 웹 기반 저비용

## 3. 대상 고객 (기준서 1장)
| 고객 | 하고 싶은 일 |
|------|--------------|
| 제조 중소·중견기업 (생산기술·생산관리·경영) | 라인 레이아웃·사이클·물류 검증, 투자 효과 비교, 가동 현황 가시화 |
| 설비 제작사 · 시스템 통합(SI)사 | 납품 설비를 3D·신호 단위로 재현해 고객에게 제안·검증 |

## 4. 모듈 대응표 (우리 이름 ↔ 기준서 이름)
| 우리 이름 (BSE) | 기준서 모듈 | 하는 일 | 시기 |
|-----------------|-------------|---------|------|
| **Build** | 머신빌더 + 팩토리빌더 | 블록으로 설비를 만들고(머신빌더), 평면도 위에 설비를 배치해 공장을 만든다(팩토리빌더) | V1 |
| **Simulate** | 시뮬레이션 | 신호·동작·물류 흐름을 돌려 처리량·병목을 계산하고, 시나리오를 비교·최적화한다 | V1 |
| **Evolve** (Monitor) | 디지털 섀도 (옵션 모듈) | 실제 PLC 태그로 화면이 움직이고 현황을 본다 | V2 |

기준서는 하나의 편집기 위에 "범위 2개(설비·공장) + 모드 3개(편집·실행·비교)"로 설명합니다. BSE는 사용자에게 보여 주는 작업 흐름 이름입니다.

## 5. 구성
- 랜딩 페이지: https://bse-digital-twin.vercel.app (Build / Monitor 입구)
- BSE Studio: 빌더 앱 (`BSE-Digital-Twin` 저장소 `apps/web`에 처음부터 작성, D-31·D-32. 기존 `BSE_STUDIO` 폴더는 VEXPLOR 파생 AAS 도구라 참고용)
- Monitor: 디지털 섀도 화면 (V2)

## 6. 하지 않는 것 (기준서 1·2장)
- 대규모 3D 에셋 카탈로그 (블록은 "형식 + 치수"이지 메이커 제품 하나하나가 아님)
- 여러 산업 프로토콜 게이트웨이를 직접 만드는 것 (Node-RED 등 외부 솔루션 사용)
- 정밀 물리 시뮬레이션을 직접 만드는 것 (MuJoCo / Isaac 사용, V3)
- 범용 로봇 오프라인 프로그래밍, PLC 프로그램 작성
- ERP/MES 대체 (연동 대상으로만 봄)

## 7. 성공 기준 = 기준서 V1 완성 기준 (9.2절)
1. 도면 없는 설비를 블록으로 L2(기구·신호)까지 재현하고, 태그 ON/OFF로 동작이 확인된다
2. 평면도 위에 공장을 구성하고 설비 카드를 배치해 자재 흐름과 동선이 연결된다
3. 라인의 처리량·병목·가동률을 계산하고 대안 시나리오와 비교표로 출력된다
4. 레이아웃 최적화 과정이 세대별 애니메이션으로 재생된다
5. DXF를 CAD에서 열 수 있고, I/O 리스트 엑셀이 표준 양식으로 들어오고 나간다
6. 기준 설비 3종·기준 공장 1개로 위 1~5가 자동 테스트로 통과한다

랜딩 페이지 기준은 그대로: 처음 3초 안에 "산업용 디지털 트윈 도구"임을 알 수 있다.
