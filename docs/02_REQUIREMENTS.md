| 항목 | 내용 |
|------|------|
| 주 역할 | 무엇을 만들지, 기능 범위와 완료 기준 |

> 빌더 앱의 기능 목록은 [11 개발 지침서 R1](11_BSE_DT_DEV_STANDARD.md) 9장과 부속 "기능 로드맵" 엑셀(기능 127개)이 원본입니다 (D-19). 여기서는 요약만 적습니다.

## 1. 우선순위 표기
- 빌더 앱: 기준서의 **V1 / V2 / V3** 와 등급(본체 · 삭제 · 보류 · 옵션 모듈 · 타 플랫폼 이관 · 외부 솔루션)을 그대로 씁니다. 새 기능 제안은 기능 로드맵 엑셀에 등급을 달아 백로그로 보냅니다.
- 랜딩 페이지만 예전 표기 유지: **P0** 없으면 출시 불가 / **P1** 출시 직후 / **P2** 나중에

## 4. 완료 기준
- 빌더 앱: [01 개요](01_OVERVIEW.md) 7절의 V1 완성 기준 6개. 게이트 통과는 "데모가 돈다"가 아니라 "완성 기준이 자동 테스트로 통과한다"
- 랜딩 페이지: 위 표의 완료 기준

## 5. 화면 이외의 요구사항
- 성능: 블록 200개·설비 50대에서 끊김 없이 (기준서 11주차 기준). 지원 브라우저는 Chrome·Edge 최신 2버전, WebGL2 필수, 1920×1080 기준
- 지원 환경: PC 우선. 태블릿·휴대폰 뷰어는 V2
- 접근성: "움직임 줄이기" 설정 시 애니메이션 정지 (랜딩)
- 언어: 빌더 앱은 한국어 기본, 영어는 V2. 랜딩은 KR/EN
