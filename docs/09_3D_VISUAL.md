# 09. 3D 비주얼 가이드

| 항목 | 내용 |
|------|------|
| 주 역할 | 3D 장면·움직임의 규칙과 컨셉 |
| 부 역할 | 성능 예산과 기기별 기준 |
| 주 담당 / 부 담당 | 3D 테크니컬 아티스트 리드 / 리드 프로덕트 디자이너 |
| 마지막 수정 | 2026-10-30 |

## 1. 컨셉: "남색 청사진 위의 공장"
첫 화면 가운데에 남색 청사진(블루프린트) 스타일로 그린 3D 공장이 놓입니다. 설계 도면처럼 차분하게 보이다가, 클릭하면 지붕과 로봇 팔이 들어 올려지며 공장 안이 드러납니다. 디지털 트윈의 Build(공장을 설계하고 구성한다)를 바로 보여주는 장면입니다.

## 2. 장면 구성 (이름표 3개, 영어만)
| 이름표 | 내용 |
|--------|------|
| Factory | 선으로 그린 공장 (72 × 64). 기둥 위에 비쳐 보이는 톱니 모양 지붕(4칸 쏘투스 지붕), 벽 없음 |
| Work cell | 공장 안, 높은 격자망 펜스 두 개 사이의 컨베이어. 바닥에 고정, 사방에 여유 공간 |
| Robot cell | 공장 안, 작업 셀에서 조금 떨어져 서 있는 로봇 팔 3대 |
- 이름표는 긴 지시선으로 연결, 언어 전환과 상관없이 항상 영어
- 이름표 점(지시선 시작점) 위치:
  - Factory: 지붕 오른쪽 끝 바로 바깥, 앞뒤 기준 가운데
  - Work cell: 두 펜스 사이, 컨베이어 벨트 끝을 지난 곳에서 약간 오른쪽, 뒤쪽 펜스에 가깝게
  - Robot cell: 오른쪽 로봇 팔 옆
- 바닥 격자: 90 × 80만 표시. 배경 전체 격자는 없음
- 위치: 제목과 버튼 사이, 화면 가운데
- 넣지 않는 것: 로고, 큐브

## 3. 움직임 규칙
- **클릭 영역**: 바닥 격자 부분만 클릭됨. 그 위에서 마우스 커서가 손가락 모양으로 바뀜
- **클릭**: 지붕은 높이, 뒤쪽으로 들어 올려지고 로봇 팔은 살짝만 올라감. 작업 셀(컨베이어)은 그대로. 다시 클릭하면 내려옴
- **키보드**: Tab으로 장면을 선택한 뒤 Enter로 열고 닫음
- **없는 것**: "Click" 안내 문구, 마우스를 올렸을 때 빛나는 효과, 가만히 있을 때 들썩이는 움직임
- **카메라**: 고정 (돌거나 움직이지 않음)
- 원칙: 움직임은 "공장 안을 들여다보는" 의미가 있을 때만, 튀는 효과 없이 차분하게

## 4. 선·색·글자
- 바탕: 짙은 남색 청사진
- 선: 밝은 하늘색 선, 은은한 빛 번짐(글로우)
- 이름표: 짧은 영어 이름만 (설명 문장 없음)

## 5. 기기별 기준
| 상황 | 동작 |
|------|------|
| PC | 바닥 격자를 클릭해서 열고 닫음, 키보드는 Tab → Enter |
| 휴대폰 | 바닥 격자를 탭해서 열고 닫음. **할 일: 장면이 작게 보이는 문제 개선** |
| 움직임 줄이기 설정 | TODO (정지 화면 권장) |
| 3D 미지원 브라우저 | TODO (배경 없이 페이지는 그대로 동작 권장) |

## 6. 지나온 버전 (채택하지 않음)
| 버전 | 내용 | 결과 |
|------|------|------|
| 큐브 로고 | 큐브가 B/S/E 삼각형으로 흩어졌다 모임 | 제외 (모이는 과정·이후가 아쉬움) |
| 큐브 공장 스캔 | 큐브 격자 + 컨베이어 + 스캔 막 | 제외 |
| 엠블럼 | 장면 안에 로고 표시 | 제외 |
| 마우스 올리기(hover) 공장 | 따뜻한 회색 종이 바탕, 마우스를 올리면 열림, 터치 화면은 자동 반복 | 클릭 방식으로 변경 |
| "Click" 안내 문구 | 장면 아래 깜빡이는 영어 안내 | 제거 (커서 변화로 대체) |
| 회색 종이 클릭 공장 | 공장 / 작업 셀 / 로봇 팔 이름표(KR/EN), 층층이 열림 | 남색 청사진 버전으로 교체 |
| 청사진 1차 (07:17) | 공장은 왼쪽, 작업 셀·로봇은 오른쪽에 따로 배치, 바닥 격자 80 × 60 | 작업 셀·로봇을 공장 안으로 옮김 |
